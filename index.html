Why BastiaOS

A modern OS that is built to last

Everything you expect from a Linux desktop — with a core that cannot silently break, drift or be tampered with.

Immutable core

The root filesystem is read-only. Your system stays exactly as it was shipped — no configuration drift, no surprises.

Atomic updates

Updates are written to a standby slot and switched in one step. If anything fails, BastiaOS rolls back on its own.

Verified boot

UEFI Secure Boot, signed Unified Kernel Images, dm-verity and TPM2 measurements protect every step of startup.

Reproducible builds

Same source, same bytes. Anyone can rebuild BastiaOS and verify it matches the official release.

Sandboxed apps

Thousands of applications from Flathub, isolated from the base system with fine-grained permissions.

Fast & lightweight

A minimal base with no bloat. Targeting under 10 seconds to desktop and less than 500 MB of RAM at idle.

Security by design

A chain of trust from firmware to desktop

Every component that runs during boot is cryptographically verified before it executes. If a single byte of the system image is altered, BastiaOS refuses to boot it.

  • Signed Unified Kernel Images (UKI)
  • Read-only root protected by dm-verity
  • TPM2-measured boot and sealed secrets
  • Minimal attack surface and secure defaults

Atomic A/B updates

Updates that never break your machine

BastiaOS keeps two copies of the system. New versions are installed in the background to the inactive slot while you keep working. A reboot switches slots instantly — and if the new version fails to boot, you are back on the previous one automatically.

  • No half-applied upgrades
  • Automatic rollback on failure
  • Signed, delta-friendly system images

Transparent by default

Built in the open, verifiable by anyone

BastiaOS is built with Buildroot from pinned, checksummed sources. Every architectural decision is documented in public ADRs, and every release ships with a full SBOM.
